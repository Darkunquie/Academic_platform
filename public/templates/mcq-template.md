# MCQ Upload Template

Use the exact format below. Mark the correct option with a `*` before its text.

## Rules

- Each question starts with `Q: `
- Options are lines starting with `- `
- Mark the correct option with a `*` before its text, e.g. `- *Paris`
- Optional `Explanation: ...` line after options
- Optional `Difficulty: easy | medium | hard` line
- Blank line separates questions

## Examples

Q: What is the capital of France?
- London
- Berlin
- *Paris
- Madrid
Explanation: Paris has been the capital of France since the 5th century.
Difficulty: easy

Q: Which keyword in JavaScript declares a constant binding?
- var
- let
- *const
- def
Explanation: const creates a read-only binding to a value.
Difficulty: easy

Q: Time complexity of binary search on a sorted array of size n is:
- O(n)
- *O(log n)
- O(n log n)
- O(1)
Explanation: Each step halves the search space.
Difficulty: medium

Q: Which HTTP status indicates a successful resource creation?
- 200 OK
- *201 Created
- 204 No Content
- 301 Moved Permanently
Explanation: 201 is returned when a new resource has been created.
Difficulty: medium

Q: Which data structure uses LIFO order?
- Queue
- *Stack
- Heap
- Linked list
Difficulty: easy
